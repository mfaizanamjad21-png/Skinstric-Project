# 🧴 Skinstric AI — AI Skincare Analysis Platform

Skinstric AI is a modern **AI-powered skincare web application** designed to provide users with an interactive experience for exploring skincare analysis and personalized skincare information.

The project was built as a frontend software engineering project, focusing on modern UI design, responsive layouts, reusable components, API integration, and an engaging user experience.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/mfaizanamjad21-png/Skinstric-Project.git
```

### 2. Navigate to the Project

```bash
cd Skinstric-Project
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The application should be available at:

```text
http://localhost:3000
```

---

## 📦 Build for Production

To create a production build:

```bash
npm run build
```

Then start the production server:

```bash
npm start
```
